## g01 — 实事求是

```yaml
id: g01
term: 实事求是
type: term
source_chapter: 改造我们的学习（1941）
author_definition: >
  "实事"就是客观存在着的一切事物，"是"就是客观事物的内部联系，即规律性，
  "求"就是我们去研究。我们要从实际情况出发，从其中引出其固有的而不是臆造的规律性，
  即找出周围事变的内部联系，作为我们行动的向导。而要这样做，就须不凭主观想象，
  不凭一时的热情，不凭死的书本，而凭客观存在的事实，详细地占有材料，
  在一般原理的指导下，从这些材料中引出正确的结论。
key_distinction: >
  常识用法 = "踏实做事""不弄虚作假"；毛的用法 = 从客观事实中找出内在规律的方法论，
  是认识论层面"如何获得真知"的完整程序（占有材料→分析研究→引出规律→指导行动）。
why_it_matters: >
  下游 skill 的核心认识论基础。所有"分析问题""制定策略"类 skill 都以这一方法为前提：
  先占有真实材料，再用科学方法加工，最后引出规律。是毛选方法论的元方法。
tags: [认识论, 信息加工, 核心概念]
```

## g02 — 有的放矢

```yaml
id: g02
term: 有的放矢
type: term
source_chapter: 整顿党的作风（1942）
author_definition: >
  拿一句通俗的话来讲，就是"有的放矢"。"矢"就是箭，"的"就是靶，放箭要对准靶。
  ……这种态度，就是有的放矢的态度。"的"就是中国革命，"矢"就是马克思列宁主义。
  我们所以要找这根"矢"，就是为了要射中国革命和东方革命这个"的"的。
key_distinction: >
  常识用法 = "有针对性"；毛的用法 = 理论必须以解决实际问题为目的，
  反对"无的放矢"（为理论而理论）。是"实事求是"的形象化表达，强调目的性。
why_it_matters: >
  下游 skill 需要"理论与实践结合"这一原则时引用。映射到商业场景：
  任何方法论框架都应以解决具体问题为目标，反对为了方法论而方法论。
tags: [认识论, 目的性, 理论联系实际]
```

## g03 — 去粗取精、去伪存真、由此及彼、由表及里

```yaml
id: g03
term: 去粗取精、去伪存真、由此及彼、由表及里
type: term
source_chapter: 实践论（1937）
author_definition: >
  要完全地反映整个的事物，反映事物的本质，反映事物的内部规律性，
  就必须经过思考作用，将丰富的感觉材料加以去粗取精、去伪存真、
  由此及彼、由表及里的改造制作工夫，造成概念和理论的系统，
  就必须从感性认识跃进到理性认识。
key_distinction: >
  这不是修辞，而是一套信息加工的四步操作程序：(1) 去粗取精——从海量材料中筛选关键信息；
  (2) 去伪存真——辨别真伪，剔除虚假信息；(3) 由此及彼——建立信息之间的联系；
  (4) 由表及里——从现象深入到本质。是从感性认识到理性认识的具体方法。
why_it_matters: >
  下游"实事求是信息加工法" skill 的核心操作步骤。映射到商业场景：
  从海量数据/用户反馈中提取决策信号的标准流程。
tags: [认识论, 信息加工, 四步法, 核心概念]
```

## g04 — 矛盾

```yaml
id: g04
term: 矛盾
type: term
source_chapter: 矛盾论（1937）
author_definition: >
  事物的矛盾法则，即对立统一的法则，是唯物辩证法的最根本的法则。
  ……矛盾存在于一切过程中，并贯穿于一切过程的始终。
  ……不同质的矛盾，只有用不同质的方法才能解决。
key_distinction: >
  常识用法 = "冲突""不一致"；毛的用法 = 事物内部对立统一的两个方面，
  是一切事物发展的内在机制和根本动力。矛盾不是需要消除的"问题"，
  而是需要认识和利用的"发展机制"。
why_it_matters: >
  毛选方法论的哲学基石。下游"矛盾分析法" skill 的核心概念。
  理解矛盾 = 理解事物发展的动力来源，是所有分析和策略的起点。
tags: [辩证法, 核心概念, 分析框架]
```

## g05 — 主要矛盾

```yaml
id: g05
term: 主要矛盾
type: term
source_chapter: 矛盾论（1937）
author_definition: >
  任何过程如果有多数矛盾存在的话，其中必定有一种是主要的，
  起着领导的、决定的作用，其他则处于次要和服从的地位。
  因此，研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，
  就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。
key_distinction: >
  常识用法 = "最重要的问题"；毛的用法 = 在多个矛盾中起领导/决定作用的那个，
  抓住它则其他矛盾迎刃而解。不是"最大的问题"，而是"牵一发而动全身的关键节点"。
why_it_matters: >
  下游"主要矛盾判定法" skill 的核心。在复杂局面中找到杠杆点，
  避免平均用力。映射到商业：找到制约增长的核心瓶颈。
tags: [辩证法, 优先级, 杠杆点, 核心概念]
```

## g06 — 矛盾的主要方面

```yaml
id: g06
term: 矛盾的主要方面
type: term
source_chapter: 矛盾论（1937）
author_definition: >
  矛盾着的两方面中，必有一方面是主要的，他方面是次要的。
  其主要的方面，即所谓矛盾起主导作用的方面。
  事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的。
  然而这种情形不是固定的，矛盾的主要和非主要的方面互相转化着，
  事物的性质也就随着起变化。
key_distinction: >
  不仅要找到"哪对矛盾最重要"（主要矛盾），还要判断"矛盾双方谁占主导"
  （矛盾的主要方面）。事物的性质由主要方面规定，且主要方面会互相转化——
  这意味着强弱、优劣的地位不是固定的，可以逆转。
why_it_matters: >
  下游"以弱胜强" skill 的理论基础。弱者可以通过正确策略使矛盾的主要方面
  发生转化（从敌强我弱转化为我强敌弱），这是所有"逆转"策略的哲学根据。
tags: [辩证法, 力量对比, 转化, 核心概念]
```

## g07 — 矛盾的特殊性

```yaml
id: g07
term: 矛盾的特殊性
type: term
source_chapter: 矛盾论（1937）
author_definition: >
  矛盾的普遍性即寓于矛盾的特殊性之中。……不同质的矛盾，只有用不同质的方法才能解决。
  ……用不同的方法去解决不同的矛盾，这是马克思列宁主义者必须严格遵守的一个原则。
key_distinction: >
  强调每个具体矛盾都有其独特性质，不能用万能公式套用。
  这与"具体情况具体分析"直接对应——反对教条主义，
  要求针对具体时间、地点、条件制定特殊策略。
why_it_matters: >
  下游所有 skill 的"因地制宜"原则来源。提醒用户：
  毛选提供的是思维框架而非万能药方，必须结合自身具体情况灵活运用。
tags: [辩证法, 反教条, 具体分析]
```

## g09 — 自觉的能动性

```yaml
id: g09
term: 自觉的能动性
type: term
source_chapter: 论持久战（1938）
author_definition: >
  一切事情是要人做的，持久战和最后胜利没有人做就不会出现。
  做就必须先有人根据客观事实，引出思想、道理、意见，提出计划、方针、
  政策、战略、战术，方能做得好。思想等等是主观的东西，做或行动是主观见之于客观的东西，
  都是人类特殊的能动性。这种能动性，我们名之曰"自觉的能动性"，
  是人之所以区别于物的特点。
key_distinction: >
  常识的"主观能动性"容易理解为"想干事"；毛的"自觉的能动性"强调两个条件：
  (1) 必须基于对客观规律的认识（自觉），不是盲目蛮干；
  (2) 包含认识世界（引出思想）和改造世界（付诸行动）两个环节。
  不等于主观主义，而是在客观条件许可范围内的主动作为。
why_it_matters: >
  下游"主观能动性"相关 skill 的理论基础。指出人在客观约束条件下仍有巨大主动空间，
  关键是"基于正确认识的主动行动"，而非"不顾条件的盲目冒进"。
tags: [认识论, 主体性, 行动哲学, 核心概念]
```

## g10 — 群众路线 / 从群众中来到群众中去

```yaml
id: g10
term: 群众路线
type: term
source_chapter: 关于领导方法的若干问题（1943）
author_definition: >
  在我党的一切实际工作中，凡属正确的领导，必须是从群众中来，到群众中去。
  这就是说，将群众的意见（分散的无系统的意见）集中起来（经过研究，化为集中的系统的意见），
  又到群众中去作宣传解释，化为群众的意见，使群众坚持下去，见之于行动，
  并在群众行动中考验这些意见是否正确。然后再从群众中集中起来，
  再到群众中坚持下去。如此无限循环，一次比一次地更正确、更生动、更丰富。
  这就是马克思主义的认识论。
key_distinction: >
  常识用法 = "走群众路线"（往往沦为敷衍口号）；毛的用法 = 完整的认识-实践循环：
  分散意见→集中研究→系统化→回到实践检验→再集中→再实践。本质上是认识论，
  以群众实践为认识源泉和检验标准，是一个无限迭代优化的过程。
why_it_matters: >
  下游"群众路线" skill 的核心。映射到商业：用户驱动产品开发的闭环方法论——
  从用户反馈中提取需求，产品化后回到用户中验证，持续迭代。
tags: [认识论, 领导方法, 迭代循环, 核心概念]
```

## g11 — 一般号召与个别指导相结合

```yaml
id: g11
term: 一般号召与个别指导相结合
type: term
source_chapter: 关于领导方法的若干问题（1943）
author_definition: >
  任何工作任务，如果没有一般的普遍的号召，就不能动员广大群众行动起来。
  但如果只限于一般号召，而领导人员没有具体地直接地从若干组织将所号召的工作深入实施，
  突破一点，取得经验，然后利用这种经验去指导其他单位，就无法考验自己提出的
  一般号召是否正确，也无法充实一般号召的内容，就有使一般号召归于落空的危险。
key_distinction: >
  这是"群众路线"的操作化展开：(1) 先提一般号召动员全局；
  (2) 再选若干点深入实施，取得一手经验；(3) 用点上的经验修正和完善一般号召；
  (4) 以修正后的一般指导推广全局。是"从个别到一般，再从一般到个别"的循环。
why_it_matters: >
  下游"一般与个别结合" skill 的核心。映射到商业：
  公司战略传达 + 局部试点 + 全面铺开的工作方法论。
tags: [领导方法, 试点推广, 循环迭代]
```

## g12 — 持久战

```yaml
id: g12
term: 持久战
type: term
source_chapter: 论持久战（1938）
author_definition: >
  中日战争既然是持久战，最后胜利又将是属于中国的，那末，就可以合理地设想，
  这种持久战，将具体地表现于三个阶段之中。第一个阶段，是敌之战略进攻、
  我之战略防御的时期。第二个阶段，是敌之战略保守、我之准备反攻的时期。
  第三个阶段，是我之战略反攻、敌之战略退却的时期。
key_distinction: >
  持久战不等于"慢慢打"，而是以时间换空间的系统性战略：
  通过延长战线，在过程中积累力量、消耗对手，最终实现优劣转化。
  三阶段模型（防御→相持→反攻）为弱者提供了完整的长期博弈路线图。
why_it_matters: >
  下游"持久战三阶段模型" skill 的核心框架。映射到商业：
  创业公司面对行业巨头的三阶段竞争路线图——先防守生存，再积蓄力量，最后反攻。
tags: [战略, 长期博弈, 以弱胜强, 核心概念]
```

## g13 — 防御中的进攻、持久中的速决、内线中的外线

```yaml
id: g13
term: 防御中的进攻，持久中的速决，内线中的外线
type: term
source_chapter: 论持久战（1938）
author_definition: >
  在第一和第二阶段即敌之进攻和保守阶段中，应该是战略防御中的战役和战斗的进攻战，
  战略持久中的战役和战斗的速决战，战略内线中的战役和战斗的外线作战。
key_distinction: >
  这是毛选最精妙的辩证法应用：战略层面和战役/战术层面采取截然相反的策略。
  整体上是防御的，但每一场具体战斗必须是进攻的；整体上是持久的，
  但每一场具体战斗必须是速决的；整体上被包围，但局部上要反包围敌人。
  不是自相矛盾，而是不同层面的策略辩证统一。
why_it_matters: >
  下游"战略-战术辩证法" skill 的核心。映射到商业：
  公司整体处于守势时，在每个具体产品线/细分市场要采取进攻姿态；
  长期竞争中每次出手要快准狠。
tags: [战略, 辩证法, 攻防转换, 核心概念]
```

## g14 — 主动性、灵活性、计划性

```yaml
id: g14
term: 主动性、灵活性、计划性
type: term
source_chapter: 论持久战（1938）
author_definition: >
  自觉的能动性，说的是自觉的活动和努力，是人之所以区别于物的特点。
  这里说的主动性，说的是军队行动的自由权，是用以区别于被迫处于不自由状态的。
  行动自由是军队的命脉，失了这种自由，军队就接近于被打败或被消灭。
key_distinction: >
  三者构成完整的行动方法论：(1) 主动性 = 行动自由权，力争主动、力避被动；
  (2) 灵活性 = 根据实际情况随时调整部署的能力；(3) 计划性 = 预见和准备。
  注意：计划性不等于刻板执行，而是"相对的固定性的计划"，必须随情况变化而修正。
why_it_matters: >
  下游"主动性灵活性计划性" skill 的三要素。映射到商业：
  在竞争中保持主动权（不被对手牵着走），保持灵活（随时调整策略），
  同时有计划（不盲目行动）。
tags: [战略, 行动方法论, 自由权]
```

## g15 — 歼灭战

```yaml
id: g15
term: 歼灭战
type: term
source_chapter: 中国革命战争的战略问题（1936）；论持久战（1938）
author_definition: >
  歼灭战和集中优势兵力、采取包围迂回战术，同一意义。

  与其多线平庸不如单线打透，集中资源拿下关键客户/细分市场，
  彻底消灭竞争对手在该领域的影响力。
tags: [战术, 资源集中, 核心概念]
```

## g16 — 游击战 / 十六字诀

```yaml
id: g16
term: 游击战

source_chapter: 抗日游击战争的战略问题（1938）；星星之火，可以燎原（1930）

why_it_matters: >
  下游"灵活机动的十六字诀" skill 的核心。映射到商业：
  小公司在巨头薄弱环节建立利基市场，灵活进退，不与巨头正面硬刚。
```

## g20 — 两类矛盾（对抗性 / 非对抗性）

```yaml
id: g20
term: 两类矛盾（对抗性 / 非对抗性）
type: term
source_chapter: 关于正确处理人民内部矛盾的问题（1957）
author_definition: >
  敌我之间的矛盾是对抗性的矛盾。人民内部的矛盾，在劳动人民之间说来，
  是非对抗性的；在被剥削阶级和剥削阶级之间说来，除了对抗性的一面以外，
  还有非对抗性的一面。……敌我之间和人民内部这两类矛盾的性质不同，
  解决的方法也不同。简单地说起来，前者是分清敌我的问题，后者是分清是非的问题。
  ……工人阶级和民族资产阶级之间的对抗性的矛盾如果处理得当，
  可以转变为非对抗性的矛盾。
key_distinction: >
  常识倾向于把所有矛盾都视为对抗性的（必须分出胜负）。
  毛的框架将矛盾分为两类：对抗性矛盾（敌我，用专政/强制手段解决）
  和非对抗性矛盾（人民内部，用民主/说服方法解决）。
  更关键的是：矛盾的性质不是固定的，处理方式可以改变矛盾的性质——
  处理得当，对抗性可以转为非对抗性；处理不当，非对抗性也可以激化为对抗性。
why_it_matters: >
  下游"两类矛盾区分法" skill 的核心。映射到商业：
  区分"不可调和的冲突"（与直接竞争对手）和"可以通过沟通解决的分歧"
  （团队内部、合作伙伴之间），用不同策略处理不同性质的矛盾。
tags: [辩证法, 冲突管理, 核心概念]
```

```yaml
id: g25
term: 实践是检验真理的标准

  MVP验证→理论提炼→产品迭代的增长飞轮，任何战略假设必须通过市场实践来检验和修正。
```
