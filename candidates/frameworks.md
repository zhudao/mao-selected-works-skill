# 毛泽东选集 -- 思维模型/决策框架/推理方法 候选列表

> 来源: 毛泽东选集第1-5卷
> 提取原则: 去除纯政治内容，所有框架映射到商业/创业/个人发展场景

---

- id: f01
  title: 认识论循环 (实践-认识-再实践)
  type: framework
  source_chapter: 实践论 (1937)
  source_quote: |
    "通过实践而发现真理，又通过实践而证实真理和发展真理。从感性认识而能动地发展到理性认识，又从理性认识而能动地指导革命实践，改造主观世界和客观世界。实践、认识、再实践、再认识，这种形式，循环往复以至无穷，而实践和认识之每一循环的内容，都比较地进到了高一级的程度。"
  summary: |
    人类认识遵循"感性认识 -> 理性认识 -> 实践检验"的螺旋上升路径。先在实践中获得表面印象和感性经验，通过反复积累产生概念飞跃，形成理性判断，再回到实践中验证和修正。
    商业映射: 创业就是不断循环的 MVP 迭代。先做最小可行产品投放市场（感性认识），从用户反馈中提炼出产品规律（理性认识），再开发下一个版本投入市场（再实践）。每次循环都比上一次更接近 product-market fit。这不是一次性决策，而是持续的感知-判断-行动回路。创业者最危险的是停在"理性认识"阶段闭门造车，或者停留在"感性认识"阶段凭直觉盲目行动。
  tags: [epistemology, iteration, lean-startup, decision]

- id: f02
  title: 主要矛盾分析法
  type: framework
  source_chapter: 矛盾论 (1937)
  source_quote: |
    "任何过程如果有多数矛盾存在的话，其中必定有一种是主要的，起着领导的、决定的作用，其他则处于次要和服从的地位。因此，研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。"
  summary: |
    在复杂系统中同时存在多个矛盾/问题，但其中必有一个是主要矛盾，决定和制约着其他矛盾的发展。抓住主要矛盾投入核心资源，其他矛盾会随之缓解或自然解决。而主要矛盾会随阶段变化而转移。
    商业映射: 创业公司面临的问题无穷无尽（产品、营销、融资、团队、技术债...），但每个阶段只有一个核心瓶颈。早期是产品-市场匹配（PMF），中期是规模化获客，后期是组织效率。集中80%精力解决当前阶段的瓶颈问题，而不是平均用力。创始人最常见的错误就是把次要矛盾当成主要矛盾来打。
  tags: [decision, analysis, prioritization, focus]

- id: f03
  title: 矛盾特殊性原则 (分类解决)
  type: framework
  source_chapter: 矛盾论 (1937)
  source_quote: |
    "不同质的矛盾，只有用不同质的方法才能解决。......用不同的方法去解决不同的矛盾，这是马克思列宁主义者必须严格遵守的一个原则。"
  summary: |
    每种矛盾都有其特殊性，不能一刀切。必须首先分析矛盾的具体性质，然后对症下药选用不同的解决方法。用错方法不但解决不了问题，反而会使问题恶化。
    商业映射: 不同类型的商业问题需要不同的方法论。增长停滞可能是产品问题（需要重新定位）、渠道问题（需要开拓新渠道）、还是市场饱和（需要寻找第二曲线）？每种根因对应完全不同的解法。用户流失、员工离职、合作方冲突也都各有不同的性质，分类诊断后再施策，是避免"拿着锤子看什么都是钉子"的关键。
  tags: [decision, analysis, diagnosis, categorization]

- id: f04
  title: 三阶段持久战模型
  type: framework
  source_chapter: 论持久战 (1938)
  source_quote: |
    "第一个阶段，是敌之战略进攻、我之战略防御的时期。第二个阶段，是敌之战略保守、我之准备反攻的时期——这个第二阶段是整个战争的过渡阶段，也将是最困难的时期，然而它是转变的枢纽。第三个阶段，是我之战略反攻、敌之战略退却的时期。"
  summary: |
    弱者面对强者的竞争，不可能速胜，也不可能速败，必然经过三个阶段：防御（守住基本盘不被淘汰）-> 相持（积蓄力量、消耗对手、寻找破局点）-> 反攻（条件成熟时集中力量一举翻盘）。第二阶段是"转变的枢纽"，最痛苦但也最关键。
    商业映射: 创业公司挑战行业巨头就是一场持久战。早期要活下来（防御期，找到生存利基），中期在细分领域深耕积累优势（相持期，建立根据地），后期在时机成熟时全面扩张（反攻期）。不能在第一阶段就全面对攻，也不能在第二阶段放弃。创业最大的危险是两个极端：悲观投降（"打不过大公司"）和盲目冒进（"三个月颠覆行业"）。
  tags: [strategy, competition, endurance, phasing]

- id: f05
  title: 反极端二分法 (既反对亡国论也反对速胜论)
  type: framework
  source_chapter: 论持久战 (1938)
  source_quote: |
    "于是失败主义的亡国论者跑出来向人们说：中国会亡......也有人说：中国很快就能胜利。二者都不对：一种是中国必亡论，一种是中国速胜论。"
  summary: |
    面对困境时，人容易陷入两种极端：失败主义（认为完全不可能成功）或冒进主义（认为可以快速解决）。正确的判断是既看到困难的真实性和长期性，也看到胜利的可能性，然后制定务实的中长期策略。
    商业映射: 面对市场寒冬或强势竞争，团队中常出现两种声音："我们肯定做不成了，趁早转型/卖掉"vs"加把劲三个月就能翻盘"。领导者必须跳出这两种极端，冷静评估真实形势：困难确实很大、周期确实很长，但只要策略正确、坚持执行，最终可以胜出。CEO 的核心工作之一就是对抗这两种情绪的蔓延。
  tags: [decision, bias, mindset, realism]

- id: f06
  title: 全局-局部决策法
  type: framework
  source_chapter: 中国革命战争的战略问题 (1936)
  source_quote: |
    "说'一着不慎，满盘皆输'，乃是说的带全局性的，即对全局有决定意义的一着......指挥全局的人，最要紧的，是把自己的注意力摆在照顾战争的全局上面。"
  summary: |
    决策者必须区分哪些局部对全局有决定意义、哪些只是次要局部。关键局部的失败会导致全局失败，但次要局部的失败可以承受。领导者应将注意力集中在关键节点上。
    商业映射: CEO 的精力分配是最重要的战略决策。融资、核心人才招聘、产品方向、关键客户——这些是对全局有决定意义的"一着"。办公室装修、非核心功能的技术选型、次要供应商的选择——这些局部即使出错也不会致命。创始人最大的时间陷阱就是把大量精力花在无关全局的细节上，而忽略了真正决定公司生死的几个决策点。
  tags: [strategy, decision, prioritization, leadership]

- id: f07
  title: 一般规律与特殊规律 (三层认知法)
  type: framework
  source_chapter: 中国革命战争的战略问题 (1936)
  source_quote: |
    "我们不但要研究一般战争的规律，还要研究特殊的革命战争的规律，还要研究更加特殊的中国革命战争的规律。"
  summary: |
    认识任何领域都分三个层次：一般规律（行业通用法则）-> 特殊规律（你的赛道/品类的特殊性）-> 更加特殊的规律（你自己面临的具体情境）。照搬一般规律而忽视特殊性，必然失败。
    商业映射: 很多创业者犯的错误是照搬"一般规律"（如硅谷的标准创业方法论、MBA 教科书），而没有深入分析自己赛道的特殊性（中国市场的独特性、垂直行业的特殊性）和自身公司的特殊性（团队基因、资源禀赋）。成功的学习方法应该是：掌握一般原理作为框架，然后花主要精力研究自己的特殊性，形成独特的战略。
  tags: [epistemology, strategy, learning, context]

- id: f08
  title: 边缘突破 + 根据地建设战略
  type: framework
  source_chapter: 星星之火可以燎原 (1930)
  source_quote: |
    "政权发展是波浪式地向前扩大的......朱德毛泽东式之有根据地的，有计划地建设政权的，深入土地革命的，扩大人民武装的路线......是正确的。"
  summary: |
    弱小力量不应追求全面出击，而应在对手薄弱的边缘地带建立稳固的根据地，站稳脚跟后再波浪式向外扩张。根据地是蓄积力量的基础，没有根据地的游击式扩张无法持久。
    商业映射: 创业公司要找到巨头忽视的细分市场作为"根据地"，在那里建立牢固的竞争壁垒（用户忠诚度、数据壁垒、供应链优势等），然后以此为基地向相邻市场波浪式扩张。不要一开始就全面开战。拼多多从五环外下沉市场建立根据地，再向一二线城市渗透，就是典型的"星星之火"策略。关键是根据地要足够扎实，否则扩张就是无本之木。
  tags: [strategy, startup, market-entry, competitive-advantage]

- id: f09
  title: 群众路线循环 (从群众中来到群众中去)
  type: framework
  source_chapter: 关于领导方法的若干问题 (1943)
  source_quote: |
    "在我党的一切实际工作中，凡属正确的领导，必须是从群众中来，到群众中去。这就是说，将群众的意见（分散的无系统的意见）集中起来（经过研究，化为集中的系统的意见），又到群众中去作宣传解释，化为群众的意见，使群众坚持下去，见之于行动，并在群众行动中考验这些意见是否正确。然后再从群众中集中起来，再到群众中坚持下去。如此无限循环，一次比一次地更正确、更生动、更丰富。"
  summary: |
    正确的决策不是领导者在办公室拍脑袋想出来的，而是从一线实践者的分散经验中提炼出来的。领导者要把零散的基层经验系统化为策略，再拿回一线验证和执行，循环迭代。每次循环都让策略更精准。
    商业映射: 产品经理最重要的工作方法就是"从用户中来，到用户中去"。从用户反馈、客服记录、销售一线的零散信息中提炼产品策略，做出来后再回到用户中验证。CEO 做战略也是一样：定期与一线销售、客户成功、客服团队沟通，从他们的碎片化经验中提炼战略洞察，而不是只看二手报告。脱离一线的决策必然失真。
  tags: [leadership, decision, user-research, iteration]

- id: f10
  title: 一般号召与个别指导相结合
  type: framework
  source_chapter: 关于领导方法的若干问题 (1943)
  source_quote: |
    "如果没有一般的普遍的号召，就不能动员广大群众行动起来。但如果只限于一般号召，而领导人员没有具体地直接地从若干组织将所号召的工作深入实施，突破一点，取得经验，然后利用这种经验去指导其他单位，就无法考验自己提出的一般号召是否正确。"
  summary: |
    领导者既要提出全局性的方向和号召，又要亲自下场在少数点上深度实践、取得一手经验。没有一般号召就没有统一方向，没有个别指导就无法验证方向是否正确、也无法积累可复制的经验。
    商业映射: CEO 提出公司战略方向（一般号召）后，必须亲自参与一两个关键项目或客户的深度执行（个别指导）。只有这样，才能判断战略是否可行，才能提炼出可复制的 SOP 给其他团队。如果只发号施令不深入一线，战略就会变成纸上谈兵。很多公司战略转型失败，根本原因就是领导层没有"个别指导"的耐心，只停留在"一般号召"。
  tags: [leadership, execution, management, validation]

- id: f11
  title: 辩证平衡框架 (论十大关系)
  type: framework
  source_chapter: 论十大关系 (1956)
  source_quote: |
    "提出这十个问题，都是围绕着一个基本方针，就是要把国内外一切积极因素调动起来，为社会主义事业服务。......你如果是真想发展重工业，那你就要注重农业、轻工业。"
  summary: |
    面对多重对立关系（重工业vs轻工业、沿海vs内地、国家vs个人、中央vs地方），不能非此即彼地选择一边，而要在对立中找到辩证平衡。看似矛盾的两个目标，通过巧妙的比例安排和时序设计，可以互相促进。关键是"真想"——你要A的最好方式往往不是直接追逐A，而是先做好B来支撑A。
    商业映射: 企业经营充满这样的辩证关系：短期利润vs长期投入、产品vs销售、增长vs利润、集权vs授权、创新vs效率。不是二选一，而是找到正确的比例和节奏。比如"真想做好产品"的最好方式可能是先让销售团队去前线带回真实的用户痛点。"真想快速增长"可能需要先在基础设施建设上多投入。领导者的核心能力就是在这些张力之间找到动态平衡点。
  tags: [strategy, dialectics, balance, systems-thinking]

- id: f12
  title: 统筹兼顾原则
  type: framework
  source_chapter: 关于正确处理人民内部矛盾的问题 (1957) / 论十大关系 (1956)
  source_quote: |
    "我们作计划、办事、想问题，都要从我国有六亿人口这一点出发......我们的方针是统筹兼顾、适当安排。"
  summary: |
    做任何决策都要从全局出发，照顾到各方利益和条件，不能只考虑单方面。统筹不是平均用力，而是在看清全局的前提下做出最优取舍和安排。
    商业映射: 产品决策要统筹技术可行性、商业价值、用户体验、团队能力。组织管理要统筹业务目标、员工发展、文化建设。资源分配要统筹当前生存和未来发展。统筹兼顾的本质是系统思维——任何单一维度的优化如果损害了系统整体，都是错误的。好的 CEO 永远在做多目标优化，而不是单目标最优化。
  tags: [decision, systems-thinking, balance, planning]

- id: f13
  title: 两类矛盾分类处理法
  type: framework
  source_chapter: 关于正确处理人民内部矛盾的问题 (1957)
  source_quote: |
    "在我们的面前有两类社会矛盾，这就是敌我之间的矛盾和人民内部的矛盾。这是性质完全不同的两类矛盾......敌我之间和人民内部这两类矛盾的性质不同，解决的方法也不同。"
  summary: |
    面对冲突和矛盾，首先要分类：是对抗性矛盾（零和博弈，必须有一方胜出）还是非对抗性矛盾（可以通过协商、调整、转化来解决）。不同性质的矛盾用不同方法处理，把非对抗性矛盾当成对抗性来处理会激化矛盾，反之则会让原则问题被模糊。
    商业映射: 企业管理中，合作方的利益分歧、团队内部的意见冲突大多是非对抗性矛盾，应通过沟通、机制设计、利益调整来解决。而价值观根本冲突、恶意违约、竞争对手的恶意抄袭则是对抗性矛盾，需要果断斗争。管理者最常见的错误是对本应是内部协调的问题采取了对抗手段（如公开冲突、零和博弈），或者对本应坚决斗争的问题一味退让。
  tags: [decision, conflict-resolution, management, categorization]

- id: f14
  title: 不对称战略 (游击战升维法)
  type: framework
  source_chapter: 抗日游击战争的战略问题 (1938)
  source_quote: |
    "游击战争的战略问题是在这样的情况之下发生的：中国既不是小国，又不像苏联，是一个大而弱的国家被另一个小而强的国家所攻击......敌人占地甚广但兵力不足，在占领区留了很多空虚的地方。"
  summary: |
    弱者对抗强者时，不能用强者的规则和方式打正面战。要利用自身"大而弱"的特点（规模大、分布广但单体力量弱），找到强者"小而强"的盲区（兵力不足、覆盖有限），在这些真空地带建立局部优势。游击战不是战术而是战略——当你的弱小是结构性的，你的策略也必须升维到战略层面。
    商业映射: 创业公司面对巨头不能用巨头的打法（拼资金、拼渠道、拼品牌）。要找到巨头覆盖不到的细分市场、服务不到的下沉用户、来不及跟进的新场景，在这些巨头力所不及的"空虚地带"建立根据地。这不是权宜之计而是战略选择——把"弱小"转化为"灵活"和"专注"的优势。拼多多的社交裂变、字节跳动的算法分发，都是典型的"游击战升维"。
  tags: [strategy, competition, asymmetric, startup]

- id: f15
  title: 歼灭战原则 (集中优势兵力)
  type: framework
  source_chapter: 中国革命战争的战略问题 (1936)
  source_quote: |
    "对于人，伤其十指不如断其一指；对于敌，击溃其十个师不如歼灭其一个师。歼灭战和集中优势兵力、采取包围迂回战术，同一意义。"
  summary: |
    资源有限时，不要追求面面俱到的"击溃战"（每个方向都推进一步但都不彻底），而要在选定的关键方向上集中绝对优势资源打"歼灭战"（彻底解决一个问题）。一个歼灭战的成果远大于十个击溃战。

  type: framework
  source_chapter: 矛盾论 (1937)
  source_quote: |
    "事物发展的根本原因，不是在事物的外部而是在事物的内部，在于事物内部的矛盾性......唯物辩证法认为外因是变化的条件，内因是变化的根据，外因通过内因而起作用。鸡蛋因得适当的温度而变化为鸡子，但温度不能使石头变为鸡子，因为二者的根据是不同的。"
  summary: |

    商业映射: 面对同样的市场环境（政策变化、经济周期、技术变革），有的公司逆势增长，有的公司一蹶不振。根本原因不在外部环境而在内部：团队能力、产品竞争力、组织韧性、现金流健康度。创业者常犯的错误是把失败归因于外部环境（"市场不好""政策不行"），而忽视自身内部的问题。正确的归因方式是：外部条件是给定的，我能在内部做什么来适应和利用这些条件？
