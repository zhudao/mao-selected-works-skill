## p01 — 没有调查就没有发言权

```yaml
id: p01
title: 没有调查就没有发言权
type: principle
source_chapter: 反对本本主义 (1930) / 改造我们的学习 (1941)
source_quote: |
  "没有调查就没有发言权，夸夸其谈地乱说一顿和一二三四的现象罗列，都是无用的。任何一个部门的工作，都必须先有情况的了解，然后才会有好的处理。"（改造我们的学习）
summary: |
  任何决策和判断必须建立在系统的实地调查和数据分析之上，而非主观臆断或照搬理论。决策前必须详细占有材料，了解真实情况，才能做出正确判断。映射到商业场景：产品决策前必须做用户调研、市场分析，用数据驱动而非拍脑袋决策。
tags: [调查研究, 决策方法, 信息获取, 实事求是]
```

## p02 — 实事求是信息加工四步法

```yaml
id: p02
title: 实事求是信息加工法 — "去粗取精、去伪存真、由此及彼、由表及里"
type: principle
source_chapter: 实践论 (1937) / 中国革命战争的战略问题 (1936)
source_quote: |
  "将丰富的感觉材料加以去粗取精、去伪存真、由此及彼、由表及里的改造制作工夫，造成概念和理论的系统，就必须从感性认识跃进到理性认识。"（实践论）
summary: |
  面对海量原始信息，必须通过四步加工法提取决策信号：(1) 去粗取精——过滤噪音保留关键信息；(2) 去伪存真——识别并排除虚假数据；(3) 由此及彼——建立信息之间的关联；(4) 由表及里——从现象深入到本质规律。映射到商业场景：从用户反馈、市场数据、竞品信息中提取决策依据的系统方法论。
tags: [信息处理, 分析方法, 决策方法, 实事求是]
```

## p03 — 认识来源于实践（实践认识论）

```yaml
id: p03
title: 认识来源于实践 — 感性到理性再到实践的螺旋上升
type: principle
source_chapter: 实践论 (1937)
source_quote: |
  "认识从实践始，经过实践得到了理论的认识，还须再回到实践去。认识的能动作用，不但表现于从感性的认识到理性的认识之能动的飞跃，更重要的还须表现于从理性的认识到革命的实践这一个飞跃。"（实践论）
summary: |
  知识的形成是一个螺旋上升的过程：从实践经验中获得感性认识，通过思考上升为理性认识，再回到实践中去检验和发展。真理只能通过实践来检验。映射到商业场景：MVP验证(感性) -> 提炼方法论(理性) -> 产品迭代(再实践)的增长飞轮，以及"干起来再学习"的敏捷迭代思维。
tags: [认知方法, 学习方法, 实践论, 迭代思维]
```

## p04 — 抓住主要矛盾

```yaml
id: p04
title: 抓住主要矛盾 — "捉住主要矛盾，一切问题迎刃而解"
type: principle
source_chapter: 矛盾论 (1937)
source_quote: |
  "研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。万千的学问家和实行家，不懂得这种方法，结果如堕烟海，找不到中心，也就找不到解决矛盾的方法。"（矛盾论）
summary: |
  在复杂的局面中，必须找到起决定性作用的那个核心矛盾/瓶颈。一旦抓住并解决了它，其他问题会连锁解决。切忌平均用力、面面俱到。映射到商业场景：识别制约业务增长的核心瓶颈(如获客、留存、变现中的关键一环)，集中资源突破这一个杠杆点。
```

## p05 — 不同质的矛盾用不同质的方法

```yaml
id: p05
title: 不同质的矛盾用不同质的方法解决
type: principle
source_chapter: 矛盾论 (1937)
source_quote: |
  "不同质的矛盾，只有用不同质的方法才能解决。用不同的方法去解决不同的矛盾，这是马克思列宁主义者必须严格地遵守的一个原则。教条主义者不遵守这个原则，他们不了解各种革命情况的区别，因而也不了解应当用不同的方法去解决不同的矛盾，而只是千篇一律地使用一种自以为不可改变的公式。"（矛盾论）
summary: |
  世界上没有万能公式，一切方法必须结合具体时间、地点、条件。不同性质的问题需要用不同的方法来解决，切忌照搬照抄。映射到商业场景：不同发展阶段(0-1 vs 1-10 vs 10-100)需要不同的管理方法；不同市场(B2B vs B2C)需要不同的增长策略；不可盲目照搬他人的成功模式。
tags: [矛盾分析, 因地制宜, 反教条主义, 具体分析]
```

## p09 — 持久战三阶段模型

```yaml
id: p09
title: 持久战三阶段模型 — 防御、相持、反攻
type: principle
source_chapter: 论持久战 (1938)
source_quote: |
  "持久战的三个阶段：第一个阶段，是敌之战略进攻、我之战略防御的时期。第二个阶段，是敌之战略保守、我之准备反攻的时期。第三个阶段，是我之战略反攻、敌之战略退却的时期。三个阶段中，敌我力量的变化将循着一定的道路前进。"
summary: |
  弱者对抗强者的长期博弈分为三个阶段：(1) 防御期——保存实力、消耗对手；(2) 相持期——积蓄力量、等待时机；(3) 反攻期——条件成熟后全面出击。核心是以时间换空间，在过程中积累力量、转化优劣。映射到商业场景：创业公司面对行业巨头的三阶段竞争路线图——早期避开正面竞争、中期在利基市场站稳脚跟、后期条件成熟时规模化扩张。
tags: [持久战略, 三阶段模型, 长期博弈, 以弱胜强]
```

## p11 — 群众路线 — 从群众中来到群众中去

```yaml
id: p11
title: 群众路线 — "从群众中来，到群众中去"的无限循环
type: principle
source_chapter: 关于领导方法的若干问题 (1943)
source_quote: |
  "在我党的一切实际工作中，凡属正确的领导，必须是从群众中来，到群众中去。这就是说，将群众的意见（分散的无系统的意见）集中起来（经过研究，化为集中的系统的意见），又到群众中去作宣传解释，化为群众的意见，使群众坚持下去，见之于行动，并在群众行动中考验这些意见是否正确。然后再从群众中集中起来，再到群众中坚持下去。如此无限循环，一次比一次地更正确、更生动、更丰富。"（关于领导方法的若干问题）
summary: |
  正确的决策必须来源于用户/群众的实践，又回到用户/群众中去检验。具体流程：收集分散的用户反馈 -> 系统分析提炼为策略 -> 回到用户中执行和验证 -> 再次收集反馈，如此无限循环，每次迭代都更接近正确。映射到商业场景：用户驱动产品开发的闭环方法论——用户调研 -> 产品迭代 -> 用户验证 -> 再调研的持续循环。
tags: [群众路线, 用户驱动, 闭环方法论, 产品迭代]
```

```yaml
  沟通和表达的八大反面清单：(1) 空话连篇言之无物；(2) 装腔作势借以吓人；(3) 无的放矢不看对象；(4) 语言无味缺乏生动性；(5) 只罗列现象不分析本质；(6) 不负责任不认真准备；(7-8) 坏的文风会扩散传播造成大面积危害。正面方法：观察 -> 提出问题 -> 分析问题 -> 解决问题。映射到商业场景：报告/演示/沟通的质量标准——说真话、有内容、针对听众、说人话、有分析、负责任。
```

## p18 — 提出问题-分析问题-解决问题的方法论

```yaml
id: p18
title: 观察-提出-分析-解决问题的思维框架
type: principle
source_chapter: 反对党八股 (1942)
source_quote: |
  "什么叫问题？问题就是事物的矛盾。哪里有没有解决的矛盾，哪里就有问题。提出问题，首先就要对于问题即矛盾的两个基本方面加以大略的调查和研究，才能懂得矛盾的性质是什么，这就是发现问题的过程。要解决问题，还须作系统的周密的分析过程。一篇文章或一篇演说，如果是重要的带指导性质的，总得要提出一个什么问题，接着加以分析，然后综合起来，指明问题的性质，给以解决的办法。"（反对党八股）
summary: |
  解决任何复杂问题的通用思维框架：(1) 观察现象，发现问题(矛盾所在)；(2) 对矛盾的两个方面进行调查，提出问题；(3) 系统周密地分析问题，暴露内部联系；(4) 综合判断，指明性质，给出解决方案。映射到商业场景：面对业务问题时的标准分析流程——识别问题 -> 收集数据 -> 分析根因 -> 制定方案。
```
