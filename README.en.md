# Mao Selected Works Skill

An AI skill pack that distills *Selected Works of Mao Zedong*, Volumes 1-5, into 25 reusable modules for cognition, strategy, organization, and execution.

This is not a book summary. The book is the source material; the skills are the usable output.

## What It Helps With

- Finding the main contradiction in a messy situation
- Competing as a weaker player against a stronger opponent
- Turning scattered information into judgment
- Making investigation, user feedback, and organizational correction executable
- Balancing cooperation, competition, and team governance

## What Was Distilled

The pack contains 25 triple-verified skills across five areas:

- **Cognition and epistemology**: practice-based cognition, seeking truth from facts, contradiction analysis, contradiction specificity, internal-cause analysis
- **Investigation and information gathering**: investigation research, mass-line feedback loops
- **Competitive strategy**: protracted-war stages, asymmetric strategy, base-area building, concentration of force, flexible competitive rhythm
- **Action philosophy**: strategic confidence with tactical seriousness, learning through action, mental reset, initiative-flexibility-planning balance
- **Organization and management**: conflict classification, constructive correction, organizational diagnosis, pilot-first rollout, independent cooperation, multi-task rhythm, dialectical balance

1. Start with `INDEX.md` to see the full skill map and dependency graph.

3. Use its trigger conditions, execution steps, and boundaries directly in your agent or prompt workflow.
4. Use `test-prompts.json` to verify correct and incorrect trigger scenarios.
