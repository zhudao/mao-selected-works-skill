# Mao Selected Works Skill

一套可直接使用的 AI skill 工具包——把《毛泽东选集》第 1-5 卷中的认知方法、战略判断、组织管理和执行方法拆成了 25 个可单独触发、也可组合调用的方法论模块。

这不是一本书的摘要页。书是这些 skill 的来源，不是首页主角。

## 这套 skills 能解决什么问题

- 面对复杂局面时，不知道哪个问题才是主要矛盾
- 资源有限、对手更强，需要设计长期竞争路线
- 团队有很多信息和意见，但无法加工成有效判断
- 想把调查研究、群众路线、复盘纠偏变成可执行流程
- 在合作、竞争、组织建设之间需要动态平衡，而不是靠口号推进

## 蒸馏了什么

从《毛泽东选集》第 1-5 卷中提取了 25 个经过三重验证的 skill，覆盖五个维度：

- **认知与认识论**：`shijian-renshilun`（实践认识论）、`shishiqiushi-sigao`（实事求是信息加工法）、`maodun-fenxi`（矛盾分析法）、`maodun-techuxing`（矛盾特殊性原则）、`neiyin-juedinglun`（内因决定论）
- **调查与信息获取**：`diaocha-yanjiu`（调查研究法）、`qunzhong-luxian`（群众路线循环）
- **竞争战略**：`chijiuzhan-san-jieduan`（三阶段持久战）、`buduicheng-zhanlue`（不对称战略）、`xingxingzhihuo-genjudi`（星星之火与根据地建设）、`jianmiezhan-jizhong-bingli`（集中优势兵力）、`shiliuzijue`（十六字诀）、`zhanlue-zhanshu-bianzheng`（战略战术辩证法）
- **心态与行动哲学**：`zhanlue-miaoshi-zhanshu-zhongshi`（战略藐视、战术重视）、`cong-zhanzheng-xuexi-zhanzheng`（在行动中学习）、`fangxia-baofu-kaidong-jiqi`（放下包袱开动机器）、`zhudongxing-linghuoxing-jihuaxing`（主动性、灵活性、计划性）
- **组织与管理**：`lianglei-maodun`（两类矛盾）、`chengqianbihou-zhibing-jiuren`（惩前毖后、治病救人）、`zuzhi-jiupian-zhenduan`（组织纠偏诊断）、`yiban-gebie-zhidao`（一般号召与个别指导）、`tongyi-zhanxian-duli`（统一战线中的独立自主）、`tan-gangqin`（弹钢琴工作法）、`bianzheng-pingheng`（辩证平衡）、`youxiao-goutong-wenti-jiuej`（有效沟通与问题解决）

提取过程从候选框架、原则、案例、反例和术语中筛选，最终保留 25 个可迁移、可触发、可验证的方法论单元。

## 效果示例

### 示例 1：问题太多，先解决哪个

**用户问题**

"公司现在产品、销售、交付、团队都有问题，每个部门都说自己最重要，我该先抓哪里？"

**skill 如何判断**

- 先触发 `maodun-fenxi`，列出所有关键矛盾并寻找主要矛盾
- 如果主要矛盾已经清楚，再接 `jianmiezhan-jizhong-bingli`，判断如何集中资源突破
- 如果问题性质不同，再接 `maodun-techuxing`，避免用同一套方法处理所有问题

**最终回答示例**

> 先不要按部门排优先级，而要看哪个矛盾牵动其他矛盾。把问题改写成几组张力：产品价值与用户留存、销售承诺与交付能力、团队扩张与管理密度、现金流与增长节奏。逐一追问：如果这个问题解决了，其他问题会不会同步缓解？如果它恶化，其他问题会不会跟着恶化？如果答案集中指向"交付能力跟不上销售承诺"，那当前主要矛盾不是销售不努力，也不是产品功能少，而是承诺-交付失衡。下一步应集中兵力修复交付闭环，而不是平均给每个部门发任务。

### 示例 2：弱者如何和强者竞争

**用户问题**

"我们是小团队，行业巨头已经进来了。正面打肯定打不过，但完全避开又没有空间，怎么办？"

**skill 如何判断**

- 先调用 `buduicheng-zhanlue`，判断能否重新定义竞争范式
- 再接 `xingxingzhihuo-genjudi`，寻找边缘市场和根据地
- 如果是长期竞争，再调用 `chijiuzhan-san-jieduan`，设计防御、相持、反攻阶段

**最终回答示例**

> 不要把问题定义成"我们怎么在巨头规则里赢巨头"。弱者的第一步是换战场：找到巨头因为成本结构、组织惯性或品牌定位而不愿深入的小场景。这个场景要小到巨头看不上，但深到你能形成密度。先建根据地：核心用户、稳定交付、口碑循环、数据反馈。等这个根据地能自我供血，再做波浪式扩张。你不是一开始就追求全面胜利，而是先让强者的优势在局部失效。

## 这些 skill 是怎么生成出来的

这套 skill 使用 **cangjie-skill** 的 RIA-TV++ 流水线生成，整个流程分六个阶段：

1. **整书理解（Adler 分析）**——用 Mortimer Adler 的分析阅读法，对全书做结构、解释、批判、应用四步拆解，产出 `BOOK_OVERVIEW.md`
2. **并行提取**——同时派 5 个专项提取器（框架、原则、案例、反例、术语），从原文中提取候选方法论单元
3. **三重验证筛选**——每个候选必须通过三项检验：书中至少有 2 处独立佐证（跨域）、能回答书中未明说的新问题（预测力）、不是常识（独特性）。通过率通常只有 25-50%
4. **RIA++ 构造**——将验证通过的内容按 R（原文引用）/ I（用自己的话重写）/ A1（书中案例）/ A2（未来触发场景）/ E（可执行步骤）/ B（边界与盲点）六个维度结构化
5. **Zettelkasten 链接**——找出 skill 之间的依赖、对比、组合关系，生成 `INDEX.md` 和引用图
6. **压力测试**——为每个 skill 设计包含诱饵题的测试用例，未通过的回炉重做

每个 `SKILL.md` 都是这个过程的真实产出，保留了 `candidates/` 和 `rejected/` 作为完整审计轨迹。

cangjie-skill 基于 RIA-TV++ 方法论，将书籍中的方法论、框架、原则提取为原子化的 skill，可被 AI agent 在真实场景中直接调用。


## 如何使用

1. 浏览 `INDEX.md` 了解 skill 全景图和依赖关系
2. 找到与你当前问题相关的 `*/SKILL.md`，直接使用里面的触发条件和执行步骤
3. 将 skill 接入你的 agent 框架，或把 prompt 作为独立工具使用
4. 用 `test-prompts.json` 验证 skill 在正确场景下触发、在错误场景下不触发
